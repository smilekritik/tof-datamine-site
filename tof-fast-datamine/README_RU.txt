# Переносимый двухэтапный пакет Datamine

Первый этап извлекает файлы из клиента игры. Второй этап обрабатывает экспорт и создаёт готовое дерево datamine/ без исходного репозитория и существующей папки Datamine.

Есть два варианта запуска:

RUN_EXPORT_SMALL.bat — короткий экспорт для обычной отправки данных.
Экспортирует все необходимые JSON. Из изображений проверяет только папки void и WorldBossList, при этом уже полученные ранее изображения из exported-images-ignore.txt пропускаются самим UnrealExporter.
Результат: raw_exports_small.zip.

RUN_EXPORT_FULL.bat — полный экспорт для обновления всей базы изображений.
Экспортирует необходимые JSON и все настроенные папки изображений без списка пропусков.
Результат: raw_exports_full.zip.

Как это работает

1. Скрипт читает путь к Tower of Fantasy из GAME_PATH.txt или предлагает выбрать папку. Файл создаётся локально только после выбора папки.
2. Предыдущая папка raw_exports удаляется.
3. Для выбранного режима формируется конфиг UnrealExporter: SMALL отключает лишние изображения на уровне конфига приложения, FULL включает полный набор.
4. Обязательные JSON проверяются, результат записывается в raw_exports/export-validation.txt.
5. После успешной проверки создаётся архив соответствующего режима.

Что отправлять kritik)

Обычно запускайте RUN_EXPORT_SMALL.bat и отправляйте raw_exports_small.zip.
RUN_EXPORT_FULL.bat и raw_exports_full.zip нужны, когда требуется полностью обновить базу картинок.

Файл exported-images-ignore.txt — одноразовый индекс изображений, которые уже были выгружены в raw_exports_temp. Его не нужно пересоздавать при каждом запуске.

Multype этим pipeline не обновляется.

Обработка

После экспорта запустите RUN_PROCESS.bat. Скрипт принимает raw_exports_full.zip, raw_exports_small.zip или папку raw_exports. Успешная обработка создаёт dist_datamine_bundle/datamine и dist_datamine_bundle.zip. Полученную папку datamine можно скопировать поверх основной папки Datamine с заменой файлов.

Пакет содержит физические копии canonical processors и вручную поддерживаемые входы для переименований предметов, карточек FCE, дат OOW и каталога баффов. package-manifest.json хранит хеши processors и список входов. Скрипт проверяет обязательные JSON и outputs до публикации. При ошибке raw inputs сохраняются, а пустой или stale bundle не публикуется. Временная распаковка ZIP удаляется только после успешной проверки; export-only ZIP остаётся.

Чтобы поменять сохранённый путь к игре, удалите GAME_PATH.txt. Не распространяйте пакет с локальным путём конкретной машины.
