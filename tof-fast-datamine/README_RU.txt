Есть два варианта запуска:

RUN_EXPORT_SMALL.bat — короткий экспорт для обычной отправки данных.
Экспортирует все необходимые JSON. Из изображений проверяет только папки void и WorldBossList, при этом уже полученные ранее изображения из exported-images-ignore.txt пропускаются самим UnrealExporter.
Результат: raw_exports_small.zip.

RUN_EXPORT_FULL.bat — полный экспорт для обновления всей базы изображений.
Экспортирует необходимые JSON и все настроенные папки изображений без списка пропусков.
Результат: raw_exports_full.zip.

Как это работает

1. Скрипт читает путь к Tower of Fantasy из GAME_PATH.txt или предлагает выбрать папку. Файл создаётся локально только после выбора папки.
2. Предыдущая папка raw_exports удаляется.
3. Для выбранного режима формируется конфиг UnrealExporter: SMALL отключает лишние изображения на уровне конфига приложения, FULL включает полный набор.
4. Обязательные JSON проверяются, результат записывается в raw_exports/export-validation.txt.
5. После успешной проверки создаётся архив соответствующего режима.

Что отправлять kritik)

Обычно запускайте RUN_EXPORT_SMALL.bat и отправляйте raw_exports_small.zip.
RUN_EXPORT_FULL.bat и raw_exports_full.zip нужны, когда требуется полностью обновить базу картинок.
