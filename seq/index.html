Datamined source only

The values on this page are extracted from datamined game data in DT_MonsterStaticData_Overseas.json . For the follow-up calculations, the page applies the sequential base resist of 7500, which is treated here as 34.71%. So for everyone who want to understand how much dmg needed - imagine u add resist ignore, but boss stay invulnerable first 3s (-100% dmg dealt during it), then boss set 1-2 shields (-50% dmg dealt during it), then ur build can miss compare to cactus gameplay (1-3% miss) = total result with 50% ignore same number dmg needed.
