Datamine tools

Local editors for Datamine content. Each tool edits live values and exports drop-in files to replace in datamine/.

OOW

Origin of War

Upload and bind monster portrait artwork to codeNames, then export the mapping and image assets.

Exports to datamine/oow/assets/monsters/ + scripts/monster-image-mapping.json
Open editor →
FCE

FCE Card Builder

Build and edit FCE boss mechanic cards with live 1920×1080 preview, PNG and JSON export.

Exports to datamine/fce/data/bosses/{slug}.json (+ PNG)
Open editor →
SEQ

Effective HP Editor

Loaded-values table with double-click Effective HP mechanics overrides, then export overrides.

Exports to datamine/seq/data/seq-mechanics-overrides.json
Open editor →
MULTYPE

Rename Editor

Category, subcategory, and file rename editor with live matrix and dictionary export.

Exports to datamine/multype/data/renames.base.json
Open editor →
ITEMS

Item Rename Editor

Searchable items table with double-click rename editing for Gacha + MMO datasets.

Exports to datamine/items/data/merged_mapping_with_original*.json
Open editor →
